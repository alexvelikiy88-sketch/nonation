## Специальная отчётность для VISUAL GATE

Если PR затрагивает визуал, камеру, NPC-поведение/POI или WebGL первого квартала, кроме обычной сдачи приложить:

- **Канон:** ссылка на `Documentation/VISUAL_CANON_RU.md`, какие `VIS-##` задачи закрываются, сравнение со SHA-256 оригинального утверждённого PNG.
- **Скриншоты:** исходный и новый кадр из **настоящей Unity WebGL в Chromium** с одинаковой канонической 3/4 камерой; подтверждённые build SHA, FPS и browser proof.
- **Игровое действие:** реальные NPC/магазины/кафе/работа/транспорт и управление, а не постановочный статичный art-render.
- **Графика:** Avatar/Animator/skin/LOD проверки, разные материалы/освещение, полный source+license+hash manifest.
- **Профилирование:** платформа, разрешение, браузер, FPS/p50/p95, draw calls, triangles и memory **только если реально измерены**.
- **Самооценка и blockers:** отмечать ещё присутствующие procedural placeholders, ошибки clipping/lighting, проблемы с моделями/правами. Визуальный `DONE` требует не только CI, но и проверки руководителя + явного одобрения владельца.

Не выдавать раннюю работоспособную alpha за эстетически принятую игру. Не править чужие личные отчёты; manager handoff должен иметь собственное авторство.
