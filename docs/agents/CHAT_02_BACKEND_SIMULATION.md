## НОВАЯ ЗАДАЧА / VIS-04 — настоящая жизнь в утверждённом игровом квартале

**С 24.10.26 утверждён [визуальный канон NONATION](../../Documentation/VISUAL_CANON_RU.md).** Город должен выглядеть как изометрический современный квартал у набережной и **вести себя как живое место**, а не как статичная модель с бессмысленно ходящими NPC. Продолжай существующую архитектуру Domain/.NET и сохранения, не создавай новую симуляцию с нуля и не редактируй Unity/Graphics файлы напрямую.

Твой измеримый продуктовый результат:

1. Определи стабильные ID и правила **POI** первого квартала: магазин, кафе, рабочее место, зона отдыха/скамейка, входы и точки выгрузки товара. Согласуй DTO/события с CHAT 01/03, не привязывай экономику к визуальной геометрии.
2. Расширь/протестируй задачи жителей: путь к магазину → реальная покупка по существующему кошельку и запасам → выход; путь к кафе/отдыху → изменение потребности; работа/товары/логистика, короткие социальные встречи и повторное планирование при занятости/непроходимости цели.
3. Покажи разнообразие разумных состояний людей на площади, в кафе, у витрин и на набережной: стоять, сидеть, гулять, заходить, возвращаться, работать; не просто случайные перемещения или анимации без правил.
4. Сохрани финансовую idempotency, запасы и грузовой escrow, bounded replay, fixed tick, remote spectator read-only и защиту от double-spend. Никаких открытых writable money API.
5. Дай тесты воспроизводимых NPC-сценариев и actual state snapshots со ссылкой на CI, которые Unity может использовать для настоящих анимаций и игровых действий.

**Нельзя закрыть задачу VIS-04 только серверным тестом.** Для полной приёмки нужно доказать действия живых NPC **в новом Unity WebGL квартале**: маршруты, покупки, кафе, работа и взаимодействие с объектами. По поводу `MirGame.cs`, `MirCity.cs`, NavMesh/сцены или аниматоров оформить `CROSS-OWNER REQUEST` руководителю.

**Главный визуальный договор:** работа Backend должна увеличивать плотность правдоподобных действий, не разрушая FPS и стабильность экономики; «40 стоящих капсул» не считаются выполнением.
