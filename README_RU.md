# MIR Dockside · Unity 6 playable vertical slice (alpha)

Это **исходный Unity-проект**, а не переименованный HTML и не готовый WebGL-билд. Код перенесён на C#. В проекте имеется игровой район с управляемым NPC, 39 автономными NPC, машинами, магазином, кафе, квартирами, производственным пригородом и оплачиваемым грузовым маршрутом. **Полный JavaScript-мир V10/V11 НЕ перенесён**: сейчас это первый игровой вертикальный срез, а не завершённая игра на 5000 жителей.

## Запуск — 5 шагов

1. Установи Unity Hub, редактор **Unity 6 / 6000.0.30f1** (или совместимую 6000.0 LTS) и **Web Build Support** через Unity Hub. Нужен компьютер с Windows/macOS/Linux, не телефон.
2. Распакуй **всю папку `MIR_Dockside_Unity6`**. В Unity Hub выбери **Add > Add project from disk** и укажи эту папку. **Не запускай файлы C# или `ProjectVersion.txt` отдельно.**
3. Открой проект. Unity Package Manager установит URP и glTFast (нужно интернет-подключение). Импорт FBX и больших GLB может быть длительным; дождись конца импорта и компиляции скриптов.
4. В верхнем меню Unity выбери **MIR → 01 — Rebuild Playable District**. Скрипт создаст Animator Controller из реально импортированных Quaternius FBX, сохранит валидные Humanoid prefabs и сцену `Assets/MIR/Scenes/MIR_PlayableDistrict.unity`.
5. Открой сцену и нажми **Play**. Затем **MIR → 03 — Audit Model and Economy**, чтобы проверить реальные Unity Avatar и бухгалтерские инварианты; отчёт появится в `BuildReports/MIR_Unity_Audit.txt`.

## Как собрать браузерную версию

После успешного запуска сцены: **MIR → 02 — Build WebGL**. Unity должна иметь установленный Web Build Support. В результате редактор создаёт `Build/WebGL` с HTML, WebAssembly и игровыми файлами. Их следует размещать на HTTP(S)-сервере. **Готового WebGL в текущем архиве нет**: среды для запуска Unity Editor здесь не было.

## Движения — главное изменение

В игровых `Assets/MIR/Art/Quaternius` есть **не GLB из предыдущей браузерной версии, а исходные FBX, специально выпущенные под Unity**:

- `UAL1_Standard_Unity.fbx` — 46 AnimationStack, включая исходную A_TPose.
- `UAL2_Standard_Unity.fbx` — 43 AnimationStack, включая исходную A_TPose.
- `Mannequin_F.fbx` — модель с Humanoid Avatar, на которую можно применить клипы.

`MIR → Rebuild` создаёт Unity Animator Controller с Blend Trees и состояниями для контекстных действий. Скрипт **проверяет `avatar.isValid && avatar.isHuman` перед выдачей импортированного персонажа в мир**. При ошибке рига будет показан временный шарнирный манекен, а не сломанная T-поза. Походки отличаются длительностью/темпом/формальной манерой. *Полную визуальную проверку клипов без Unity Editor не провели.*

## Дополнительные архивы

Соседний архив `MIR_Dockside_Unity6_Optional_Assets.zip` содержит Honda NC, Freya.blend и дополнительную Pinkdress. Для Honda — распакуй, в редакторе открой **MIR → 05 — Import Honda Test Asset (NON-COMMERCIAL)** и выбери папку `Honda_Civic_BTCC_2023_NC`. Это только тестовая автомобильная модель; её колесные оси, двери, масштаб и салон после импорта нужно проверить в Unity. **Нельзя использовать эту модель в коммерческой WebGL-публикации.**

## Что осталось перенести из старого MIR

Основная архитектура жизни из V10/V11, 60 товарных цепочек, все 36 профессий, пассажирский транспорт, полноценные ДТП, полиция/скорая/пожарные, семьи/дети, 24/7 сервер и входы нескольких игроков, Instagram onboarding, 3000–5000 NPC и долгосрочный баланс **НЕ перенесены**. Из старых данных перенесены JSON-каталоги 60 товаров/36 профессий только как справочные входы. Старые JSON-сохранения HTML-версии напрямую не совместимы с новой Unity-версией.

Документы: `Documentation/COVERAGE_RU.md`, `Documentation/LICENSES.md`, `Documentation/ASSET_AUDIT.json`.

## Проверка честности результата

В исходном окружении **отсутствует Unity Editor**, поэтому нельзя подтвердить сборку, рендеринг, FPS и экспорт WebGL. Выполнены только инспекция входных архивов, автоматический анализ C#-структуры и проверка комплектации файлов. Используй `MIR → Audit` после открытия проекта и смотри Console на ошибки импорта.
