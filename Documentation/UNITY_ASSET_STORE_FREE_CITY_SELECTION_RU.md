## 1. Главное правило

**Цена FREE не означает CC0 или право публиковать оригинальные FBX/Prefab/Texture в открытом GitHub.** Для перечисленных Asset Store пакетов указан Standard Unity Asset Store EULA, а не CC0. EULA допускает использование в составе самостоятельной игры, но не предоставляет общего права распространять самостоятельные редактируемые ассеты и весь исходный пакет. Приобретение/добавление в My Assets делается правообладателем соответствующего Unity-аккаунта; агент не притворяется, что пакет уже скачан.

**Статус по всем кандидатам ниже: исследовано описание и условия, ассеты НЕ скачаны и НЕ импортированы в Unity/WebGL.** Проверка качества по карточке не равна сравнению реального Prefab с каноном. Unity 6.0.58f2 отдельно подтвердить в тестовом проекте до использования.

Ссылки на лицензию: https://unity.com/legal/as-terms (Appendix 1, §2.2.1–2.2.1.1).

## 3. Как совместить разные бесплатные пакеты без визуального разрыва

1. **Один объект = один art source.** Для каждого здания хранить существующий business/home ID, позицию, collider и POI независимо от выбранного вида. В вариантах [Kenney, modular, Asset Store] виден только один MeshRenderer-set. Остальные источники не должны дублировать фасад, крышу или Collider.
2. **Масштаб в метрах:** 1 unit Unity = 1 m. Подгонка по дверям (примерно 2.0–2.4 m), окнам, этажам (~3–3.5 m), автомобилям и живым Humanoid. Только сохранение пропорций: нельзя произвольно растягивать здание независимо по X/Y/Z и искажать двери/людей. Если форма не совпадает с gameplay footprint, использовать совместимый другой Prefab или дополнительную архитектурную вставку, а не деформировать его.
3. **Стиль:** дневной мягкий свет, натуральные светлые минеральные стены, кирпич, стекло, дерево, небольшие фирменные акценты. Удалять чрезмерные кислотные, неоновые и случайные мультяшные материалы; согласовать Albedo/roughness, оттенки листвы, дорожное покрытие и цвет транспорта.
4. **Сила деталей:** герой-район (кафе, магазин, площадь, набережная) — детальные фасады и реальная геометрия; средний план — немного упрощённые модели с теми же пропорциями и материалами; очень простые пакеты — только дальний план или временный отказ.
5. **Окружение:** дороги одного масштаба и разметки, одинаковая высота бордюров, связные тротуары и проходы. Кусты, лавки и фонари одного дизайн-семейства. Перепроверять геометрию и материалы на пересечения, висящие объекты, дублирующиеся крыши, z-fighting.
6. **Шейдеры:** сейчас только Built-in для технической сборки. Не смешивать с URP-only prefabs; при несовместимом материале делать отдельный контролируемый shader/material conversion. Настоящий URP переход возможен отдельным PR после полного QA shader variants/glTFast.
7. **Производительность:** WebGL-friendly размер текстур и LOD. Не импортировать автоматически все 137 MB/155 текстур; брать выбранные компоненты при проверенной лицензии, измерять p50/p95, память, draw calls, триангуляцию и FPS.
8. **Приёмка:** для каждого нового пакета показать необработанный игровой кадр из Unity WebGL с одной камерой и сравнить с эталоном; подтвердить работающий NPC маршрут, магазин/кафе, коллизию, управление и сохранение.

## 4. Безопасный процесс получения ассетов

- На лицензированном Unity-аккаунте пользователь добавляет FREE пакеты в `My Assets`. Unity Editor/Package Manager импортирует их в частный staging-проект, НЕ в публичный исходный репозиторий.
- После фактической загрузки сохраняются: Asset Store URL, publisher, конкретная версия/дата, лицензия, `Package Content`, SHA хеши, mesh/prefab dimensions, сравнение материалов, список конфликтов/дубликатов и фактические снимки.
- Извлечённые оригинальные .FBX/.prefab/.png/.tga нельзя выгружать в общедоступный GitHub без отдельного разрешения правообладателя или независимой подходящей открытой лицензии. Для публичного репозитория фиксировать только манифест/ссылки/инструкцию импорта, пока законный приватный канал снабжения не согласован.
- Unity WebGL build с лицензированными ассетами допускается лишь в пределах лицензии и при их **embedded** использовании в самостоятельной игре. Не публиковать ассеты как открыто скачиваемые исходные пакеты.
- Если безопасный доступ к лицензированным файлам отсутствует, использовать уже имеющиеся Kenney CC0 и проверенные открытые источники, не заменять объекты иллюстрациями и не выдумывать импорт.
- **Первоочередной технический блокер:** фактический Chromium #40194385409 доказал, что NRE в glTFast `InstantiateMainSceneAsync` повторяется для Kenney зданий/деревьев. Отдельный manager PR удерживает пакетные glTF шейдеры в Resources с правдивым runtime/CI proof. Пока это не доказано — Asset Store пакеты не добавлять в релиз.

## 5. Критерий завершения выбора пакета

Пакет остаётся лишь **кандидатом**, пока нет entitlement/licensing, реальных Prefab файлов и проверки на Unity 6/WebGL. Переводить в `READY TO INTEGRATE` только после Unity Editor импорта, художественной проверки по канону, отсутствия конфликтов объектов/POI и подтверждённого законного канала поставки ассета. Цель — красивый совместимый город, а не число скачанных бесплатных моделей.
