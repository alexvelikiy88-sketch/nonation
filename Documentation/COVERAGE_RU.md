# MIR Dockside → Unity 6 — реальный статус конверсии

Статусы: `реализовано в Unity-исходниках`, `частично`, `не перенесено`. Поскольку Unity Editor в среде сборки отсутствует, нельзя выдавать предоставленный проект за уже скомпилированную или протестированную игровую Unity WebGL-сборку.

| Подсистема | Статус | Реальный объём |
|---|---|---|
| Новый Unity клиент | Реализовано в исходниках | Unity 6, сцена генерируется через меню MIR, управление игроком, камера, UI |
| Quaternius | Реализовано в исходниках | Исходные два Unity FBX и mannequin, Editor Humanoid import, автоматический Controller и Blend Trees, 87 контекстных клипов (после импорта нужно проверить точное число в Unity) |
| Персонажи из архивов | Частично | FBX Pinkdress/GIGN с автонастройкой Humanoid; GLB Maid, Floral, Casual, Girl включены; непригодные скелеты не выдаются за анимированных жителей |
| Разные походки | Частично | Два walk-цикла, индивидуальная скорость проигрывания, blend переходы, разделение маршрута и root motion. Нет доказанных perfect foot IK на всех моделях |
| Управляемый игрок | Реализовано в исходниках | WASD, Shift, E, F, R, камера Tab, окна HUD |
| Город и дороги | Частично | Один процедурный район, переходы, фонари, здания, парк, пригороды; визуал не соответствует AAA |
| Машины | Частично | Управляемые процедурные машины с колёсами, рулём, фарами; подвеска/полноценные ДТП не перенесены |
| Honda Civic | В addon | Sketchfab glTF с лицензией NC. Не включена в стандартную сцену Unity |
| Грузовая доставка | Реализовано в исходниках (срез) | Склад → рынок, физический грузовик, резерв и расчёт только при разгрузке; один маршрут |
| Базовая экономика | Реализовано в исходниках (срез) | Деньги целочисленные, запасы, платная работа, покупки, потребности, потребление, идемпотентность транзакций |
| 60 продуктов, 36 профессий | Данные перенесены | JSON оригинальных проектных каталогов. Полная игровая интеграция не выполнена |
| Сохранение | Реализовано в исходниках | PlayerPrefs / native file, идентификаторы и кошельки; импорт JSON собственной Unity схемы |
| Конвертация сохранений V10/V11 | Не перенесено | Старые JS-форматы не совместимы напрямую; требуется отдельный мигратор на реальных сохранениях |
| Общий сервер 24/7 | Не перенесено | Локальный браузерный/desktop клиент; для мультиплеера нужна серверная симуляция |
| 3000–5000 NPC | Не перенесено | Демосцена ~40 NPC. Большой город и distributed LOD не доказаны |
| Instagram → NPC | Не перенесено | Требует отдельного официального интерфейса данных/сервера |
| Автобусы, службы, семьи, поколения, полная физика транспорта | Не перенесено | Отложено до серверного ядра и надёжных моделей |

Оставленные графические ассеты, скелеты и анимации нельзя считать интегрированными в игровой процесс, если для их Unity Avatar не получен `isValid && isHuman`. Автоматическая проверка (`MIR > Audit Model and Economy`) выведет фактический статус после импорта редактором.
