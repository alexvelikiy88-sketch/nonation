# NONATION — покрытие игрового вертикального среза

**Срез и источники: 24.10.26, интеграционный [PR #19](https://github.com/alexvelikiy88-sketch/nonation/pull/19).** Формулировка «в исходниках» означает наличие кода, а не доказанный запуск WebGL или художественное качество. Единственный подтверждённый Unity export — [Cloud Build №4](https://github.com/alexvelikiy88-sketch/nonation/actions/runs/40015140424) на **другом, Unity-only SHA**.

| Подсистема | Уровень | Подтверждённый объём и ограничения |
|---|---|---|
| Unity 6 клиент | Исходники + отдельный Cloud export | `6000.0.58f2`, фиксированная сцена в Build Settings, C#; объединённый экспорт ещё проверяется |
| Игровой район | Код прототипа | Процедурные дороги, здания, рынок, кафе, ферма, гараж, склад, фонари, день/ночь |
| Жители и потребности | Код + .NET-тесты | 39 NPC + игрок; еда, энергия, работа, координаты; не массовая MMO-популяция |
| Движение и камера | Исходники | WASD, Shift, Tab, Mouse/scroll; настоящее управление в WebGL не подтверждено |
| Экономика | .NET тесты PASS | Денежные инварианты, покупки, зарплаты, запасы, лог транзакций, защита от переполнения |
| Транспорт | Код прототипа | Управляемые автомобили, базовая навигация; ДТП/транспортная физика полноценного города отсутствуют |
| Грузовая логистика | .NET тесты PASS | Склад→рынок, резерв, escrow, одноразовый расчёт, запрет двойной выдачи |
| Сохранения Unity | Исходники | Локальное PlayerPrefs/IndexedDB; браузерный save/reload ещё не подтверждён |
| Сохранения Backend | .NET и HTTP PASS | Ограниченный JSON, атомарная запись, межпроцессная lease; не SQL/cluster |
| Spectator v2 | DTO + .NET/HTTP PASS | Read-only snapshot NPC, `serverId/sequence`, CORS/HTTPS и bounded payload; не writable multiplayer |
| Humanoid персонажи | Неполный pipeline | Microsoft Rocketbox FBX, 6 MIT TGA, importer-спецификация и скрипт LOD; runtime Avatar/Animator/LOD не подтверждены |
| Процедурный fallback | Код | Шарнирные примитивы при невозможности безопасного импорта, не финальная графика |
| Анимации | Импорт/клипы подготовлены | Quaternius CC0 Idle/Walk/Run и BlendTree; индивидуальная проверка retarget и foot slide отсутствует |
| 60 товаров/36 профессий | Каталоги | JSON имеется, полная экономика цепочек не перенесена |
| Многопользовательский мир 24/7 | Не реализовано | Нет авторизованных игровых команд, SQL state sync и многопользовательской экономики |
| NPC масштаба 3000–5000 | Не реализовано | Нет измеренной производительности/LOD для тысяч жителей |
| Службы, семьи, поколения, физика ДТП | Не реализовано | Отдельные будущие подсистемы |
| HTML/MIR V10/V11 сохранения | Не совместимы | Потребуется отдельная миграция при наличии реальных исходных данных |

## Приёмка графики

FBX/текстура в Git **не равны** импортированному игровому персонажу. Нужны Unity ModelImporter, `Avatar.isValid/isHuman`, корректные skin weights/bindposes, применяемый Animator/Idle/Walk/Run, реальные отдельные LOD и измерение fps/draw calls на WebGL. Артефакты с невыясненными правами запрещены.

Подтверждённые критерии, PR и блокеры перечислены в [TASKS](../TASKS.md) и [интеграционном отчёте](INTEGRATION_REPORT_RU.md).
