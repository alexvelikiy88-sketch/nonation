# NONATION / VIS-02 — фундаментальная замена графики зданий и площади

**Статус 24.10.26:** реально изменён исходный Unity-код и создаваемые игровые 3D Mesh. **НЕ художественная приёмка**, Unity C# и shader compile / браузерная WebGL-сцена ещё не проверены. Относится только к `agent/graphics-ui`.

## Обязательный утверждённый визуальный эталон

Пользователь закрепил в **Источниках проекта NONATION** файл **`Солнечный городской квартал у набережной.png`**. Это не фоновая картинка и не свободный moodboard, а **минимальный художественный уровень** игрового vertical slice. Канонический SHA-256 оригинального PNG: `aa761600852a53231ef4fee15fda43ced35dfe40f614bed569811307bc7151a8`, разрешение 1672×941. Изображение из источников перечитано; копия RGBA с суффиксом `(1)` имеет **те же RGB-пиксели**, но другой файловый SHA. Официальным считается SHA оригинала без суффикса (см. `Documentation/VISUAL_CANON_RU.md`).

Из референса в первую очередь обязательны: плотная современная 3/4 архитектура, коммерческие нижние этажи, реальная площадь/фонтан, городской waterfront, пропорциональные машины, натуральная тёплая цветовая гамма, зелень, настоящие люди/деятельность, современный HUD. Исключено: «кубы с текстурой» в качестве принятой финальной игры.

## Что действительно заменено

Исходный `MirCity.Build()` прежде вызывал `BlockBuilding` для четырёх общественных объектов и восьми домов, а `MarketSquare()` строил примитивный плоский тротуар и 2 цилиндра. **Эти runtime-вызовы удалены.** Сами старые методы оставлены в исходнике как rollback только; новый Build больше не вызывает их.

**Новый модуль `MirArchitectureQuarter.cs`:**
- 12 зданий на прежних точных координатах и с прежними коллизионными габаритами: `Grocery store` (20,−20), `Corner cafe` (56,20), `Auto workshop` (−58,−22), `Town hall` (−20,−20), 8 домов в исходной сетке `−66 + col×36, 56 + row×38`.
- 4 материала фасадных семейств: **тёплый кирпич, светлый известняк, минеральная штукатурка, дерево**, с дополнительными архитектурными материалами (анодированный металл, стекло, карнизы/пояса, тёплые интерьерные области).
- **Не только накладные окна:** передняя стена собирается из сегментов с открытыми проёмами, за которыми расположены панели стекла, внутренние поверхности, импосты, глубинные рамы и входная коммерческая зона. Боковые окна пока декоративны и нуждаются в полном фасадном QA.
- Торговые первые этажи, металлокерамические вывески с собственной **реальной линейной 3D-геометрией букв**, козырьки, кашпо, элементы витрин; этажные пояса и настоящий рельеф фасадов.
- Для жилых зданий — балконы с объёмными поручнями, кашпо и растительностью; для подходящих крыш — террасы с перголами, а для остальных — реальные кровельные элементы/парапеты.
- Рендер геометрии **батчится по материалу** через повторно используемые `Mesh` (не отдельный `GameObject` на каждую рамку). Созданы только 12 базовых `BoxCollider` зданий. **Прямое внутреннее перемещение в здания по-прежнему отсутствует** — нужны владение сценой/логикой AGENT 01/02. Это не декларируется готовым интерьером.
- Четыре детерминированно генерируемых цветовых tile-map (`brick/stone/plaster/wood`) по **256×256 с mipmaps**, повторяемые UV в мировом масштабе. Это собственный процедурный альбедо, не скачанный высокодетальный PBR или фотография; число draw calls/FPS пока **не измерено**.

**Новый модуль `MirCivicSquare.cs`:**
- Площадь 27×27 м на прежних координатах `(20,20)`, 324 геометрические плитки, каменная кольцевая чаша фонтана, объёмная вода, цельный золотой знак NONATION, озеленённые кадки, скамьи и детали.
- Материалы сгруппированы в **9 MeshRenderer**, коллизии — 1 поверхность площади и 1 ограничивающая фонтан сфера; 2 shadowless тёплых источника света включены в существующий переключатель `MirCity.UpdateLighting`.
- Это настоящая 3D-геометрия, не PNG/фотомонтаж и не fake-сцена. Занятия NPC вокруг фонтана не моделируются отдельно в AGENT 03.

**Новый шейдер `Resources/Nonation/Architecture/ArchitecturalLit.shader`:**
- Предназначен для URP 17 (зависимость `com.unity.render-pipelines.universal:17.0.3` указана в `Packages/manifest.json`), имеет текстурное albedo, солнечное освещение, specular по smoothness/metallic, fog, shadow reception, URP shadow/depth passes; встроенный fallback для Built-in render pipeline.
- Размещён в **`Resources` внутри владения `Assets/MIR/Art/**`**, чтобы shader мог быть включён в WebGL-player без `Shader.Find` stripping. Runtime material factory проверяет загрузку и при отсутствии шейдера возвращает корректно окрашенные резервные материалы с предупреждением.
- **Это не полнофункциональный PBR/Lit URP** и не доказательство визуальной корректности/поддержки shader compiler на реальной Unity. Материал должен пройти реальную компиляцию и review по эталону.

| Свет/тени | Дополнительный шейдер и новые материалы | **Реальный GPU-рендер не проверен** |
| HUD/POI | Прежние кнопки/камера и авторский флаг V для review сохранены | Требуется обзор с живой сцены |
| Метрики | Нет фактического рендера/профиля на данном SHA | **Не измерены** |

**Обязательный gate:** `Сверка с закреплённым визуальным референсом из Источников NONATION: ВИЗУАЛЬНОЕ СООТВЕТСТВИЕ НЕ ПРОВЕРЕНО`. Приёмка только на неизменённом raw-скриншоте/видео действующей игры из Chromium с фиксированным V-кадром, названным WebGL SHA и нагрузочной метрикой. Нельзя объявлять картинку готовой по этому тексту либо исходному коду.

## Что нужно проверить в Unity AGENT 01

- Новый C# `MirArchitectureQuarter.cs` и `MirCivicSquare.cs` действительно компилируются и попадают в WebGL; `ArchitecturalLit.shader` компилируется в активной SRP/URP или встроенном pipeline, не даёт magenta/white.

- Реальные `FPS`, p50/p95 frametime, triangles, draw calls и memory в Chromium (приложить аппаратную конфигурацию). Приемлемость качества только после визуального ревью пользователя.
