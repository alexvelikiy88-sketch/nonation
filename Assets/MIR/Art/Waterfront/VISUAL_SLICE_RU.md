## Что добавлено в реальную 3D-сцену

`Assets/MIR/Art/Waterfront/MirWaterfrontQuarter.cs` строит самостоятельный **нефейковый mesh-слой окружения** в Unity, вызывается существующим `MirCity.Build()`. Один build, **без кадровых update** поверх воды, без отдельного WebGL/Editor package. Все визуальные поверхности группируются по **12 материалам в 12 MeshRenderer** (это структура исходника, **не измеренные draw calls**).

| Объект / условие | Реализация |
|---|---|
| Общая набережная | Пешеходный настил 188×20 м у южной кромки старой карты, визуально связан с существующими северо-южными тротуарами |
| Мощение | **940 плиток**, объединённых в два скульптурно-простых меша, + каменная береговая стенка и кромка |
| Вода | 56×12 трёхмерных квадов (672 сегмента), мягкая **статичная геометрическая** рябь; вода расположена за краем исходного наземного коллайдера |
| Перила / безопасность | **63 стойки**, два протяжённых трубчатых поручня, 1 физический береговой барьер |
| Озеленение | **9** объёмных деревьев с несколькими кронами + **10** посадочных групп; не sprites и не плоский рисованный backdrop |
| Скамьи | **6** деревянных с металлическими опорами |
| Велополоса | Один читаемый цветовой маршрут и размеченная отделяющая линия |
| Патио | 2 настоящих 3D-зонта, столы/сидения у кафе, но без нарисованных/fake NPC |
| Вечерний свет | 4 shadowless точечных светильника на 3D-опорах, включаемые **только ночью** через существующий `MirCity.UpdateLighting` |
| Физика | Ровно два статичных walkable BoxCollider (набережная + патио) и один береговой барьер, **не** коллайдер на каждую плитку |

Указанные количества — **детерминированные количества из исходника**, не замеры Unity profiler.

### Камера для честной side-by-side

`Assets/MIR/Scripts/MirFollowCamera.cs`: нажать **V** для фиксированного `DistrictShowcase`. Параметры в коде:

- `ShowcaseFocus=(20, 1.8, -48)`
- `Quaternion.Euler(51°, 40°, 0°)`
- `Distance=175`, `FOV=52°`
- Ракурс раскрывает южную береговую зону на переднем плане и коммерческий/площадной центр в глубине. Повторное **V** возвращает обычную изометрию; **Tab** переключает имеющиеся игровые режимы.
- `MirHUD.cs` показывает подсказку о клавише V; **H** переключает между исходной полной панелью с игровыми действиями и компактной плашкой NONATION со статусом дня/жителей и кнопкой возврата. Состояние по умолчанию — полные кнопки, игровой ввод остаётся включённым. **Никакого screenshot-concept overlay или отключения игровой симуляции нет.**
- Надёжность кадра/точный охват объектов должен подтвердить AGENT 01 из реального Chromium Unity WebGL, а не исходный код камеры.

### Почему это не финальное качество

Фоновые `BlockBuilding` остаются примитивными фасадами без настоящих архитектурных модулей/PBR. Модели нормальных персонажей в WebGL, реальные движения, игровой досуг на берегу, высокий художественный уровень воды и растительности **не доказаны**. Волны статичны, пока нет оптимизированных водных шейдеров; у застройки нет запечённого освещения; не измерены texture memory, triangles, frame time, draw calls, качество теней и материалы в браузере. Нельзя отмечать VISUAL GATE DONE.
